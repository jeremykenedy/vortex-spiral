# Vortex Spiral 1.0.0

First stable release of the animated neon vortex screensaver.

## Included

- Procedurally rendered spiral ribbons, a gently drifting center, and twinkling stars.
- Spiral arm count, movement, palette, glow brightness, and winding settings.
- Independent random choices and an option to randomize all settings on each activation.
- D-pad settings activity and a documented provider contract for compatible host applications.
- Guided ADB install/update/uninstall CLI and signed release APK with SHA-256 checksum.
- No ads, analytics, telemetry, crash reporting, tracking, app network permission, or runtime requests.

## Compatibility

Android 6.0 (API 23) or later with DreamService support. The preview renderer was installed and launched on the Android TV emulator listed in [device verification](../VERIFICATION.md). Physical Fire TV and Google TV behavior has not been verified for this release.

## Install and upgrade

Run the installer to fetch and verify the latest signed GitHub release, then install or update it on a connected TV:

```bash
python3 install.py --serial TV_IP:5555
```

Manual installation is supported with ADB. Verify the published hash before installing. Existing installs update in place with `adb install -r`; keep the same signing key for future releases.

## Version changes

This is the initial release. There are no breaking changes or migrations from an earlier Vortex Spiral version. New commands are the standalone installer, its local-APK install path, and explicit uninstall flags documented in INSTALLATION. Future same-package updates preserve preferences.
